# ZeroRadius — Requirements & Dependencies
#
# This is a Node.js/Next.js project. Dependencies are managed via npm.
# This file documents all packages for reference.
#
# ──────────────────────────────────────────────────────────────────────
# SETUP INSTRUCTIONS:
#   1. Install Node.js >= 18.x (https://nodejs.org/)
#   2. Run: npm install
#   3. Copy .env.example to .env.local and add your Gemini API key
#   4. Run: npm run dev
# ──────────────────────────────────────────────────────────────────────
#
